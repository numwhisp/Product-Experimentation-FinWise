# Onboarding Prompt, Module 2

```
I am a Product Manager developing an onboarding strategy for FinWise Co., a SaaS company providing financial-management software to small businesses.. Below are details about the user journey, target actions, user personas, and personalization rules. Please use this information to create a complete onboarding communication plan. The plan should include recommended message types, frequency, and text content for each stage of the user journey, following the specified personalization rules.

Here are the details:
Objective: The overall objective is to maximize FinWise’s revenue growth by accelerating time-to-value during onboarding and optimizing the reverse-trial paywall structure. By guiding trial users to an immediate 90-day cash runway "Aha moment" and embedding multi-seat collaborative workflows, FinWise aims to significantly lift trial-to-paid conversion above 2% and reduce the 60% annual churn without relying on additional paid acquisition spend.
User Segments: The Reactive Founder (Time-Strapped Owner): Non-financial owners with extreme complexity aversion who manage cash flow reactively, struggling with payroll anxiety and abandoning software that requires tedious manual setup.

The Operational Growth Lead (In-House Manager): Tech-savvy ops leads at growing businesses who regularly run financial scenarios, but struggle to align team reporting and validate multi-seat ROI before hitting rigid trial paywalls.

The External Advisor (Accountant / Fractional CFO): Financial experts managing multiple client accounts who demand audit-ready reports, but face friction co-piloting with clients across fragmented, siloed platforms.
User Journey: Guide users through the following stages and target actions: Sign-up → Business calibration → Bank data integration → Cash runway dashboard (Aha) → Team collaboration. Target actions: connect bank account, interact with a smart cash flow insight.
"Aha!" Moment: The aha moment is when Users view an automated 90-day cash runway forecast and resolve a live financial insight.
Purpose of Prompts: Prompts should Guide activation, highlight actionable insights, encourage collaborator invites, drive paid conversion.
Personalization Rules: Tailor prompts based on Dashboard layout, metric cards, financial insights, tailored based on business model and primary goal.. limit prompts to 1–2 per session, time them Immediately post-action & trigger-based, and use a Encouraging, authoritative, supportive tone.
Limitations & Metrics: Note Third-party bank API sync latencies, limited real-time transaction categorization capabilities, rigid trial paywall configurations.. Key success metrics include [list KPIs].

Please organize the final onboarding plan in a table with these columns: Stage, User Segment, Message Type, Frequency, Limitations, Prompt Message, Purpose, and Message Content.
```
